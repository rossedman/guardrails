The loop

Every edit fixed.
Every turn gated.

Guardrails is one Go binary wired into Claude Code's hooks. A fast inner loop on every edit, and a hard gate before Claude can call the work done.

  1. SessionStart

    {% include ".icons/material/book-open-variant.svg" %} Brief

    Claude learns the standards for the languages this repo uses before it writes a line.

    standards
  2. PreToolUse

    {% include ".icons/material/shield-lock-outline.svg" %} Guard

    Suppressions, skipped tests, lowered thresholds and risky commands are stopped before they run.

    deny · ask
  3. PostToolUse

    {% include ".icons/material/auto-fix.svg" %} Fix

    Every edited file is formatted in place, then linted and type-checked.

    < 2s
  4. Stop

    {% include ".icons/material/gate.svg" %} Gate

    Touched code must build, pass tests, hold coverage and pass every linter before the turn ends.

    block · pass

What Claude sees

One report.
Exactly where to look.

Failures name the file, the function and the fix. Claude keeps working until the gate passes, and after three blocks in a row hands the turn back to you with a summary.

  • block the gate failed, keep working
  • deny an edit that weakens the standards
  • ask irreversible infrastructure actions
  • pass the turn ends

Quick start

Installed in
two commands.

The plugin's launcher downloads the release binary for your platform, verifies its checksum and caches it. Linters and scanners arrive the same way the first time they're needed. macOS and Linux, amd64 and arm64.

{% include ".icons/material/book-open-page-variant-outline.svg" %} Full getting-started guide

  1. Add the plugin in Claude Code

    › {{ add }}
› {{ install }}

  2. Check your setup

    Shows your config, runtimes and where every tool resolves from.

    $ guardrails doctor

  3. Optional: tune it for the repo

    Writes .guardrails.yaml and path-scoped Claude rules. With no config, the defaults apply.

    $ guardrails init

  4. Run the same gate in CI

    The GitHub Action and the pre-commit hook run the same binary and config.

    $ guardrails gate --base origin/main

Languages
